# Requirements for the code

- use `yarn` for managing dependencies
- use `tailwindcss` for creating styles
- never use css in js code style

## Technical requirements
There must be separate components created outside of the page and composed on the main page.
All code must work both on a PC and mobile, have a reactive design.
All code must support dark and light mode, and different color themes and color disabilities.
It must be possible to change text sizes.


## Languages
Language switching must be supported. The mechanism must be extensible.


Languages supported out of the box:
- English
- Polish
- German
- Spanish
- Italian
