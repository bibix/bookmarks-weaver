# Bookmarks weaver

The project is a bookmarks and URL generator. It allows to template the pasted URL and provide a list of parameters.
There are two modes for the user. For beginners, there is a step by step guide, for users using it again, they can directly do all the steps.

In the middle of the top half of the page there is a large input field to enter or paste an URL.
When the user pastes the URL, all parts of the url are parsed automatically and listed below in sections:
- scheme (default to https)
- domain
- port
- path
- query parameters - as key values
- fragments

For parameters with key and value, each of them is listed separately in the query parameters section.

When the user selects any part of the URL in input field, selects any part of domain, port, path, fragment, query parameter key or value, there is a small popup with actions hovering under the selected text.

First action is marked with plus in a circle and it creates a new variable listed in the variables section below the parsed URL section.

Below variables user can add either a list of lines, or a table of lines.
In the list and in the first row of the table, the user can select the variable names that have been previously created.

The text selected by the user for each variable automatically becomes the first element in the list or in the table.
Each column in the table can be pasted separately.

Whenever user changes anything on the page, everything is updated automatically.
It is always possible to remove elements, undo and redo the actions.

Different elements of the parsed URL have different colors.

Each new variable should look like a pill with a solid background color and should replace the elements in the URL and in the parsed parts.

Users can also use variables in the input field to create a pattern how to name the bookmarks.
They can setup a folder structure in the same way. Freely using variables mixed with text to generate folder structure and bookmark names and keywords for bookmarks.

For each row in each list variable, a new combination of URLS is created. For each row in the table, a combination of all columns is used only once to create combinations of URLs.
Each new list and table leads to creation of additional combination of input parameters.

Last section of the page lists all the generated URLs and allows downloading a bookmarks file. Everything takes place in the browser with no communication with the server. The page is entirely rendered and working in the browser.

All code must work both on a PC and mobile, have a reactive design.
All code must support dark and light mode, and different color themes and color disabilities.
It must be possible to change text sizes.
